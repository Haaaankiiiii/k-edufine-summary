# 품의 한 장

K-에듀파인에서 내려받은 **품목내역 .xlsx**를 올리면, 품의 개요에 붙여 넣을 문장을 만드는 Streamlit 웹앱입니다.

**엑셀 다운로드 → 업로드 → 목적 입력 → 개요 복사**

## 사용하기

1. K-에듀파인 품목내역에 물품을 입력하고 엑셀을 다운로드합니다.
2. 앱에 파일을 올립니다. 첫 화면의 예시 토글로 연습할 수도 있습니다.
3. 목적과 구입·지급 대상을 입력합니다. 기간, 관련 문서, 사용 장소, 예산 과목은 선택입니다.
4. 표에서 품명·수량·단위·금액을 확인합니다. 필요한 셀은 직접 수정할 수 있습니다.
5. 실제 붙임 문서가 있으면 `견적서 1부`처럼 한 줄에 하나씩 입력합니다.
6. 개요 오른쪽 위 복사 버튼을 눌러 K-에듀파인에 붙여 넣습니다. 텍스트 다운로드와 문구 직접 수정도 가능합니다.

## 지원 양식과 계산

- 첨부받은 양식: 1행 `품목내역`, 3행 `순번 / * 내용 / S2B물품번호 / 규격 / 수량 / 단위 / 예상단가 / * 예상금액 / 수수료`.
- 제목 위치나 열 순서가 바뀌어도 처음 50행에서 열 제목을 찾습니다. `품명`, `단가`, `금액` 등의 대체 제목도 인식합니다.
- 여러 시트가 있으면 읽을 시트를 선택합니다. 합계·소계 행은 품목에 포함하지 않고, 원본 총합계와 현재 합계의 차이는 표시합니다.
- 10MB 이하 .xlsx, 시트당 5,000행·100열, 최대 30시트. 암호화된 파일과 구형 .xls는 지원하지 않습니다.
- 예상금액을 합산합니다. 빈 예상금액은 수량 × 단가가 정확한 원 단위 정수일 때만 계산합니다.
- 단가 × 수량과 예상금액이 다르면 확인 전까지 개요 생성을 막습니다. 확인 후에는 해당 품목에 잘못된 등식을 쓰지 않고 예상금액만 표기합니다.
- 수수료가 있으면 별도 가산 / 이미 포함 / 이번 품의 제외를 사용자가 선택합니다. 세금이나 배송비를 추측해서 추가하지 않습니다.
- 수량·단가가 없는 경우 예상금액만 표기합니다. 단위가 없으면 `수량 1`처럼 표시하므로, 필요하면 `개`, `개월`, `시간` 등을 입력하세요. 품명 속 `2개월`을 수량으로 추측하지 않습니다.
- 저장된 계산 결과가 없는 엑셀 수식은 직접 입력하거나 Excel에서 다시 계산·저장해야 합니다. 앱에서 수식을 실행하지 않습니다.
- 한글 금액은 0원부터 9,999,999,999,999,999원까지 지원합니다. 음수와 원 미만의 예상금액은 확인 후 직접 수정해야 합니다.

## 적용한 문서 형식

제공된 「★공문서 작성법.pdf」 안의 「공문서 바로쓰기」를 참고했습니다.

| 참고 위치 | 반영 사항 |
|---|---|
| PDF 4쪽 / 인쇄 쪽 3, 지출 품의서 | 목적 → 품명 → 소요 예산 → 산출 근거 |
| PDF 6쪽 / 인쇄 쪽 5, 항목 구분 | `1.` → `가.` → `1)` 순서, 하위 항목 두 칸 들여쓰기, `하.` 다음 `거.` |
| PDF 7쪽 / 인쇄 쪽 6, 숫자 | `2026. 3. 3.(화)~3. 31.(화)`, `금396,000원(금삼십구만육천원)` |
| PDF 4쪽, 붙임 예시 | `붙임  문서명 1부.  끝.` |

기본 금액 표기는 PDF에 따라 `정`을 생략하며, 사용자 예시처럼 `정`을 붙이는 옵션도 제공합니다. 84개를 넘는 품목은 `가. 품목별 내역` 아래 `1)`부터 모두 나열합니다. 기관의 모든 품의 유형을 자동 판정하는 서비스는 아닙니다. 인건비도 각 행을 읽을 수 있지만 사람별 묶음이나 시간·일수를 추측하지 않습니다.

## 내 컴퓨터에서 실행

Python 3.11 이상에서 다음을 실행합니다.

```sh
python -m venv .venv
# Windows PowerShell
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

macOS / Linux에서는 `.venv/bin/python`을 사용합니다. 실행 후 표시되는 로컬 주소를 엽니다.

## GitHub → Streamlit Community Cloud 배포

1. 이 폴더의 파일을 GitHub 저장소의 최상위에 올립니다. `.streamlit/config.toml`도 포함합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에서 GitHub 계정으로 로그인합니다.
3. **Create app → Deploy a public app from GitHub**에서 저장소를 선택합니다.
4. Branch: `main`, Main file path: `app.py`를 지정합니다.
5. Advanced settings에서 Python 3.11을 선택하고 Deploy를 누릅니다.

API 키나 별도 데이터베이스는 필요하지 않습니다. 앱 실행은 Streamlit이 담당하며 GitHub Pages에서는 실행되지 않습니다.

[공식 배포 안내](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy) · [의존성 파일 안내](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/app-dependencies)

## 데이터 처리

업로드 파일은 앱 세션의 서버 메모리에서만 처리합니다. 앱 코드에는 파일 저장, 외부 AI 호출, 데이터베이스 저장, 품목 내용 로그 기록이 없습니다. 온라인 배포에서는 파일이 Streamlit 서버로 전송됩니다. 연결 종료 이후 메모리 정리 시점은 호스팅 환경에 따릅니다. 원본 PDF·개인 엑셀 파일과 로그인 정보는 저장소에 포함하지 않습니다.

## 검증

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

엑셀 제목 행, 누락값, 저장되지 않은 수식, 합계 중복 방지, 소수 수량, 수수료, 금액 불일치, 한글 금액, 날짜, 85개 이상 항목, 붙임, 화면 입력·수정·초기화를 검증합니다. 실제 사용자 파일을 검사하려면 `KEDUFINE_TEST_XLSX` 환경 변수에 로컬 파일 경로를 지정합니다. 원본 파일은 커밋하지 않습니다.
